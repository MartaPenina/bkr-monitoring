Rules:
1. Analyze dependency chains — a downstream service failure often has an upstream root cause.
2. Check if the failing service's dependencies are also failing — that suggests cascading failure.
3. If multiple services are down, look for a common dependency (database, message queue).
4. Consider recent metric trends — gradual degradation suggests resource exhaustion.
5. Provide CONCRETE recommendations with specific commands where applicable.
6. Rate your confidence: 0.0 = pure guess, 1.0 = certain based on clear evidence.
