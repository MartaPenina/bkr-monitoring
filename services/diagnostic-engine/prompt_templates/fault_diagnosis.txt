Rules:
1. Analyze dependency chains — a downstream service failure often has an upstream root cause.
2. Check if the failing service dependencies are also failing — cascading failure pattern.
3. If multiple services are down, identify the common dependency (database, message queue).
4. Consider recent metric trends — gradual degradation suggests resource exhaustion.
5. PREDICT which services will fail next based on the dependency map — this is critical.
6. For failure_prediction.time_estimate — analyze how quickly the cascade is spreading.
7. Provide CONCRETE recommendations with specific docker commands where applicable.
8. Rate your confidence: 0.0 = pure guess, 1.0 = certain based on clear evidence.
